# Image Colorization Internship Project

Extension of a real-time image colorization training project, implementing 6 advanced colorization tasks using deep learning.

Task 1 — Real-time Multi-Object Colorization with Semantic Segmentation
Colorizes multiple objects in real-time using DeepLabV3 segmentation with class-specific color schemes for vehicles, people, plants, and more.

Task 2 — Conditional Image Colorization
Colorizes grayscale images based on user-defined color hints, allowing users to specify colors for specific regions like sky, grass, and water.

Task 3 — Context-Aware Colorization of Complex Scenes
Colorizes complex scenes like cityscapes and forests by understanding contextual relationships between objects such as shadows and reflections.

Task 4 — Time-Based Historical Image Colorization
Automatically detects the era of a historical photo and applies the appropriate color palette for that time period, with an option to manually override.

Task 5 — Cross-Domain Image Colorization
Handles multiple input domains including sketches, infrared images, and satellite imagery, applying domain-specific colorization pipelines for each.

Task 6 — Colorization of Historical Photographs
Fine-tuned colorization model focused on historical accuracy, trained specifically on historical photo datasets to replicate era-accurate color tones.


**Dataset sources, methodology, results, and metrics are documented inside each task's notebook.**
